# Operations component masters

These text-free source sheets extend the approved notebook and Founder's Ledger
direction across the remaining live UI. They cover Journal states, real event
icons, artifact reading, Studio files, control states, scrollbars, chat bubbles,
and in-world labels.

`component-preview.png` collects the key runtime crops at approximately their
authored sizes for a quick coherence check; the individual PNGs in
`assets/runtime/ui/operations/` remain the production sources of truth.

The final generation prompts requested front-facing 16-bit pixel art, quiet
nine-patch-safe centers, transparent separation, warm wood, cream parchment,
brass hardware, and the Whop palette: Vermilion `#FA4616`, Indigo `#354B98`,
Cerulean `#6196C1`, Chartreuse `#C1FA81`, Off-White `#F1F1F1`, and Charcoal
`#151515`. They prohibited baked-in text, characters, logos, scene backgrounds,
and perspective tilt. Built-in ImageGen produced the source art; runtime assets
were mechanically alpha-cleaned, sliced, and downsampled.
