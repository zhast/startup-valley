# Campus surround source

`campus-surround-master.png` is an ImageGen source master used only behind the
existing cutaway office. `dev/tools/build_polish_assets.sh` produces the native
1280 × 720 runtime texture. The office grid, walls, furniture, and navigation
remain separate and authoritative.

Built-in ImageGen prompt:

> Create an original calm 16:9 landscaped Silicon Valley startup-campus ground
> plane behind the attached Startup Valley office reference. Use top-down
> oblique cozy contemporary pixel art with hedges, grass, warm stone paths, and
> restrained modern landscaping. Keep the center quiet for the overlaid office,
> place detail around the edges, match the existing upper-left light and warm
> cozy-tech palette, and include no text, logos, UI, people, office furniture,
> building frame, black areas, watermark, or copied game-franchise elements.
