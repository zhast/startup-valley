# Coffee station v1

Four independently authored views of the shared coffee station, using the
original code-native geometry and a retained south-front ImageGen correction.
South exposes the controls, group heads, drip tray, cup cubby and cabinet doors;
North shows the rear hatch, vents and cable; East and West show distinct
reservoir and vent ends. The rendered PNGs are not rotated or mirrored.

Every layer and whole reference uses a 192×256 canvas, floor pivot `(96,192)`,
native scale 1 and nearest filtering. The original code-native layers retain
the reviewed `coffee-station-code-v1` fixture geometry. The south espresso front
uses the retained ImageGen correction in `assets/source/coffee-front-polish/`;
its whole reference is recomposed from the same ten registered layers. The
other 42 PNGs remain byte-identical to the historical fixture. All four whole
PNGs remain hash-locked reconstruction references.

This is an art/geometry promotion only. Coffee remains explicitly
**noninteractive**: the directional service sockets validate standing clearance
and approach geometry, but they do not enable clicking, pouring, drinking,
worker activity, persistence, or a new UI action.
