# Research bench v1

Four authored screen-axis views of Startup Valley's research bench. Each view
uses native transparent 192 × 320 layer canvases sharing pivot `(96, 240)`.
North is the instrument-back view; South exposes the microscope, scanner,
samples and notebook; East and West are distinct elevations rather than bitmap
rotations.

The bench remains an existing `research` interaction. This art package does not
add a new worker method or external service.
