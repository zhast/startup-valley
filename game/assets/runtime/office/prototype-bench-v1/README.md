# Prototype bench v1

Four native, independent service views of Startup Valley's shared product,
creative and engineering fabrication bench. The South tool face exposes a
printer, cutting/test surface and color-coded implements; North shows service
backs and cable management; East and West are separately authored elevations.

Canvas 192×320, floor pivot `(96,240)`, native scale only. Do not rotate,
mirror, trim or resample these layers at runtime.
