# Approval console v1

Four independently authored native service views of the shared decision
console. North shows the rear/maintenance face, South the approval interface,
and East/West their corresponding side elevations. Runtime must not rotate,
mirror, trim or resample these layers.

The exact floor pivot is `(96,208)` on a 192×288 canvas. Actual-room evidence
and the source-preserving review are under
`res://tests/output/decision-console-room/` and
`res://tests/fixtures/furniture-calibration/decision-console-v1/`.
