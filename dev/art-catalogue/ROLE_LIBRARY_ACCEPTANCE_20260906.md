# Role-kit library acceptance — September 6, 2026

## Decision and scope

The seven families below are **approved reusable art-library assets in all four
facings**, not production-integrated furniture or newly implemented employee
services. This closes their passive kit-art review. It does not close the legal,
creative or engineering kit gaps, nor the rest of the 42-family catalogue.

The main agent opened each N/E/S/W actual-room contact sheet at native size and
the enlarged isolated sheet, read the original review, and reran its structural
test against the current code. This is an explicit visual acceptance decision
under the completion goal, not automatic promotion from a test count. Older
candidate-only reviews remain the dated record of that earlier gate; this review
supersedes their pending-art-approval disposition only.

Every accepted kit supplies separately registered `surface_decor_rear` and
`surface_decor_front` RGBA layers plus its whole reconstruction reference.
Approved paths point to those existing exact exports. Production bindings,
default placement, characters, worker contracts and saves are unchanged. No
source image was repainted, regenerated, rotated or mirrored for this review.

## Visual decisions

Scores are pixel coherence / perspective / silhouette-readability /
layering-anchors / direction consistency / placement, each out of 3.

| Family | Scores | Mean | Native-size observation |
| --- | --- | ---: | --- |
| Founder strategy | 3 / 3 / 2 / 3 / 3 / 2 | 2.67 | Warm folder and open roadmap distinguish this planning set. Cards stay abstract but readable as stationery. Standing founder is a scale probe, not an approved seated pose. |
| Mina discovery | 3 / 3 / 2 / 3 / 3 / 3 | 2.83 | Cool paired wireframes and sample tokens remain visible around the monitor. East partly occludes a notebook naturally without losing the role cue. |
| Theo campaign | 3 / 3 / 2 / 3 / 3 / 3 | 2.83 | The dark three-panel creative strip and audience card differ from Mina's pale wireframes. All four views sit on the desk and preserve the same tool identity. |
| Product prototype | 3 / 3 / 2 / 3 / 3 / 3 | 2.83 | Small clamp fixture, separate parts and probe fit the research host without covering its analyzer. Details intentionally read as physical tools, not legible instrument output. |
| Growth analytics | 3 / 3 / 2 / 3 / 3 / 3 | 2.83 | Dark trace console and restrained comparison marks separate this set from campaign paper. No numbers, changing metric or false work progress is implied. |
| Finance accounts | 3 / 3 / 2 / 3 / 3 / 2 | 2.67 | Green ledger, blank keypad and receipt trays form a distinct paperwork set. Mina is only the existing contact/occlusion proxy; there is no finance employee or finance-use animation. |
| Customer success | 3 / 3 / 2 / 3 / 3 / 3 | 2.83 | The headset arch is the strongest role cue; stepped tickets and the small console remain distinct in the narrow views. No customer data or support action is introduced. |

All categories meet the minimum 2, and all means exceed 2.5. The deliberate
small-tool abstraction is a recorded limitation, not a requirement for a new
large text/metric texture. Role-specific active-use poses remain a separate
integration gate; no such pose is claimed by this passive library approval.
